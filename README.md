# Rogalique

Рогалик с процедурной генерацией уровня, врагами и переходами по этажам.
Дипломный проект курса «Разработчик игр» (XYZ School), C++ и SFML 2.5.1.

## Что внутри

- Процедурная генерация: комнаты и коридоры строятся случайно в `Dungeon`
- Враг преследует игрока жадным алгоритмом поиска пути
- Спавн игрока и врага по случайной комнате, враг не появляется рядом
- Ходовая механика по сетке с индивидуальными кулдаунами
- Камера следует за игроком

## Как запустить

Готовый exe и ресурсы выкладываются в Releases репозитория.
Скачай последний релиз, распакуй, запусти `Rogalique.exe`.

## Сборка из исходников

Нужна Visual Studio 2022 и библиотека SFML 2.5.1 в папке `SFML/` рядом с
файлом решения `rogalique.sln` (как в шаблоне курса). Конфигурация
семплирования: `Debug x64`; решение открывается и собирается в VS целиком.

Игра использует путь к ресурсам относительно папки `Resources/`,
поэтому из IDE запускать через F5 на проекте `Rogalique`.
Запуск exe вручную — только из папки с ресурсами.
